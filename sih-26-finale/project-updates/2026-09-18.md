### The thing that reframed the session

The "other repo" is not a frontend waiting for data. It is a complete, running, older system —
and our simulator is the **replacement for one box inside it**. Its own `SYSTEM_ARCHITECTURE_HLD.md`
lays out six boxes; Box 2 is the Python engine in `simulation/sandbox/`, which today writes
geo-aligned nodes and readings straight to PostgreSQL (`backend/scripts/seed.js:19-21`). Boxes
3–6 — MQTT, Postgres, Express, the Electron HMI — keep working either way.

So this was never schema design on a blank page. It is a swap, under a contract, into something
already load-bearing.

### The design, in one line

**Three channels that never mix.** Telemetry (provenance-tagged, may raise an alarm, goes to
Postgres and `/ws/run`); Scenario (`kind: "scenario"`, `store/` only, never reaches the backend,
never raises an alarm); Forecast (`kind: "forecast"`, advisory only, never raises an alarm). That
keeps `TEAM-BRIEF-V1.md:44` true as written, so nothing needed signing off. Five build sittings
A–E, in the plan file.
