# D1 — build deterministic 365-day Adriyala district dataset

## What changed

- **`simulation/scripts/build_dataset_365.py`** (new):
  Generates the real-anchored, deterministic 365-day dataset for the 31-node
  Adriyala network driving subsequent replay (D2) and FORGE evaluation (D3).
  Runs `SimulationSession` with `SessionConfig(ground="district", seed=42, tick_duration_sim_s=3600.0, save_packet_json=False, base_iso_time="2026-01-01T00:00:00Z", enable_mqtt=False, enable_db=False, quiet=True, write_nodes_csv=False)`
  for 8,760 hourly ticks without external side-effects (no MQTT/PostgreSQL network traffic).
  Output directory: `simulation/datasets/adriyala_district_365/` containing:
  1. `nodes_hourly.csv.gz`: 271,560 rows (8,760 hours × 31 nodes) + header.
     Columns: `t_hour, day, iso_time, node_id, tier, <channels...>, provenance`.
     Channel keys are read dynamically from tick output (`sorted({k for r in session.last_readings for k in r.channels.keys()})`).
     A channel not carried by a node's tier is empty (`""`), never `0`.
     Provenance column: `"LW1_fit"` for ground tiers (1A, 1B, 2A, 3), `"E1_environment"`
     for pore pressure (2B), `"LW1_fit,E1_environment"` for fault transect (1C).
     Gzip compression uses `mtime=0.0` and empty filename for bit-exact determinism.
  2. `bowl_terms.npz`:
     `px` (shape 3×121, static across-strike terms),
     `py` (shape 366×3×121, daily along-strike terms for day 0..365),
     `face` (shape 366×3, daily mining face coordinates).
  3. `events.csv`:
     Chronological timeline: `t_hour, type, node_id, detail`.
     Four event types:
     - `face_position`: daily advance of the 3 panel faces
     - `blast`: development blasts from `session._environment.blasts`
     - `fault`: hardware incidents (`battery_replaced`, `offline_start/end`,
       `gauge_stuck_start/end`, `gateway_outage_start/end`)
     - `crack_open`: first hour a node's `fissure_mm > 0` with Burland damage category
       from `sandbox.thresholds.crack_category`.
  4. `meta.json`:
     Deterministic parameters, source DOI (`10.18311/jmmf/2022/32099`), survey RMS
     (56.89 mm at epoch 210, 52.05 mm at epoch 300), file SHA-256 hashes, and per-node
     first alarm crossing day table (ADVISORY, WARNING, CRITICAL) evaluated with
     `sandbox.thresholds.classify` across tilt change since install, tensile/compressive
     strain, crack width, and pore pressure rise over the 7-day baseline.
  5. `README.md`:
     Documentation covering physical basis, schema, units, and rebuild instructions.

- **`simulation/sandbox/session.py`**:
  Added `enable_mqtt`, `enable_db`, `quiet`, and `write_nodes_csv` flags to `SessionConfig`
  (defaults preserve all existing live runtime behavior). Bypassed MQTT publishing and
  alarms when `enable_mqtt=False`.

- **`dashboard_electron/renderer/js/app.js`**:
  Added guard for `troughOverlay.init` to ensure clean startup after dead overlay removal.

- **`simulation/tests/test_dataset_365.py`** (new):
  4 unit tests using a fast 10-day build:
  - Determinism: two builds produce identical SHA-256 hashes across all files.
  - Row count: `days * 24 * 31` (7,440 data rows for 10 days).
  - Null honesty: tiers without a strain gauge have empty string (`""`), never `0` or `0.00`.
  - Replay parity: row at hour $h$ matches `session.tick()` output channel-by-channel.

## Results of the 365-day Build

- **WARNING coverage**: 29 of 30 sensing nodes reach $\ge$ WARNING.
  - Node 27 (Tier 2A at `[-270, -210]`) reaches ADVISORY (peak since-install tilt is 2.883 mm/m
    against the 3.0 mm/m WARNING threshold). Tier 2A carries only tilt and temperature;
    Node 27 sits near the outer edge of the early panel where since-install tilt is physically
    lower due to pre-settlement (as documented in `walkthroughs/data-365/G1.md` and
    `test_district.py`).
  - Per the plan rule (*"Do not tune thresholds or the ground to force the result"*),
    thresholds and ground were left unmanipulated.
- **CRITICAL coverage**: 7 nodes reach CRITICAL (`[10, 11, 15, 18, 19, 29, 30]`),
  well within the expected range of 3 to 15 nodes.
- **Total directory size**: **6.42 MB** (total size is well under 30 MB, so retained directly
  in repository without gitignoring).
