# P2 — travelling longwall face in the Knothe surface

## What changed
- `surface.py` used to treat the whole 250 x 2500 m panel as mined on day 0 (`_A = np.outer(_MASK_Y, _MASK_X)`), so the field only ever grew in magnitude, never in shape — 0 → 0.66 m by day 10, 1.10 m by day 20, 1.98 m by day 120, about 80 mm/day at the start. The module docstring already anticipated a travelling face; it had never been built.
- `constants.py` adds `FACE_START_Y_M = -(WINDOW_SIZE_M/2 + R_INFL)` (≈ −497 m, the setup room south of the window) and `FACE_ADVANCE_M_PER_DAY = 5.0`, both marked ASSUMED — flag to SCCL.
- `surface.py`: the x factor (`_MASK_X`) stays static and shared. The y factor is split into one strip per padded-grid cell over the mined interval `[FACE_START_Y_M, +L_PANEL_M/2]`, using the same fractional-coverage antialiasing as the x mask. Strip `j` is mined at `tau_j = (y_j - FACE_START_Y_M) / v` and settles as `1 - exp(-C_KNOTHE*(t - tau_j))` for `t > tau_j`, else 0.
- Every strip's 1-D y-profile is convolved with `k`, `dk` and `d2k` once at import (`_MY_K`, `_MY_DK`, `_MY_D2K`), alongside the static x profiles (`_PX_K`, `_PX_DK`, `_PX_D2K`). `channels(t)` is now only a time-weighted sum of strip profiles (`_strip_weights(t) @ _MY_K`, etc.) times the static x profile — no convolution at run time, and every derivative is still the same mask convolved with the analytic derivative kernel, never a finite difference.
- New `face_y(t)`: the face's along-strike position, clamped to `[FACE_START_Y_M, L_PANEL_M/2]`. New `bowl_profiles(t) -> (px, py)`: the separable bowl downsampled x2 to 121 points each, `px` static and `py` carrying all the time dependence.
- `_BASE_S` (the fully-settled, t→∞ field used by `server.py /config` and hypsometry) is unchanged in value — still 1.9970 m peak (T47) — just rebuilt as `_A_M * outer(_MY_K.sum(axis=0), _PX_K)`.
- Side effect: the field is no longer north/south symmetric (the face starts south and travels north), so `test_surface_field_symmetries` and the Aviershin suite in the 1000-trial stress battery now check x-symmetry only, not y.
