# P4 — 365-day FORGE timeline

## What changed
- `forge/server.py` `/forge/range` returned `end_day = max(120, ceil(latest event end))` with a `120`-day floor and no-events default. Both become 365.
- `dashboard_electron/renderer/js/sim/sim-tab.js`: `forgeState.endDay` default and the two `|| 120` fallbacks (the slider max on init, and the range-response fallback) all become 365.
- `dashboard_electron/renderer/index.html`: adds a `10 d/s` speed button between the existing `5 d/s` and `20 d/s`.
- `simulation/tests/test_forge.py`, `verify_forge_timeline.js` and `verify_forge_b3.js` updated for the new floor: the timeline test now plays from day 340 (previously would have run past the old 120-day end almost immediately), and `verify_forge_b3.js` waits longer for END.
