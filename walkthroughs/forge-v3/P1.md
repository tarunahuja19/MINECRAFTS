# P1 — collapse tilt/curvature boost only while yielding

## What changed
- `collapse.collapse_deltas` multiplied delta tilt and curvature by `yield_boost = 1 + 1.8*yield_frac`, and `_time_evolution` returns `yield_frac = 1.0` forever once a collapse finishes. So a settled pit's reported tilt stayed permanently 2.8x its true slope: a 0.5 m / 100 m Gaussian bowl should peak at `0.5*exp(-0.5)/100 = 3.03 mm/m`, the engine reported 8.49 mm/m.
- Fix: `yield_boost = 1 + 1.8*yield_frac*(1 - collapsed_frac)`, using the `collapsed_frac` (`step_frac` once collapsing, 0 before) that `_time_evolution` already returned. The boost now fades to 1 as the step completes; the pre-collapse precursor block is untouched, so the T50 warning gate still fires early.
- `test_render_placement.py`'s T58 strain-intervention gate hardcoded `_STRAIN_GEOMETRY_C = 86315.9`, which was itself 2.8x the honest value and only matched while the old boost stayed on. Rewritten to derive the constant (`B_HORIZ * 2 * exp(-1.5) * 1000`, the same derivation as `geomechanicsEngine.ts`'s `STRAIN_GEOMETRY_C`) and to assert a breach only where one is physically possible — the previous version's `ui_radius = 205.0` combined with the old inflated constant to `clamp` at `S_MAX_FULL` either way, masking the difference.
