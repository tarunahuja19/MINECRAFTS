# M1 — FORGE mini map built like the MAP tab

## What changed
- `#forge-minimap` is now a 260 px Leaflet map (`js/sim/forge-map.js`). It uses the MAP tab's tile URLs (`http://127.0.0.1:8085/tiles/satellite` plus the `labels` overlay), `mapView.xyToLatLon`, and its own copy of the `panel_outline.geojson` layer (`mapLayers.loadPanelOutline` keeps one module-level layer, so it cannot be reused). No attribution, zoom control only, `maxBounds` ±400 m, fitted to ±300 m on first show.
- Nodes use `nodeMarkers.createIcon(state, role, letter)` (now exported) with the FORGE state. Clicking one calls `simTab.selectNode(nid, 'forge')`.
- `frame.zones` → two `L.circle`s in metres (red first, white on top; crack zones are thick round-capped polylines whose weight follows zoom). `frame.cracks` → thin polylines, red when `isNew`, else orange. The preview is dashed, the target is a crosshair marker.
- A map click goes through `simTab.setForgeTarget`, the same path as `terrain-target`, so in DRAW CRACK mode it places A then B. Clicks are clamped to ±300 m.
- `renderForgeMiniMap` builds the update payload and no longer draws SVG. `onTabShown('forge')` inits the map and calls `invalidate()`.

## Not drawn any more
The old SVG also outlined not-yet-started events (with day labels) and the TILT circle. The map now shows only what the frame reports (started cave-ins and cracks); a TILT shows through its node states and strain cracks.

## Tests
`verify_forge_b3.js`: marker count equals the MAP tab's, dashed preview `getRadius()` follows the slider 30 → 200, nodes within 1.2R carry the critical icon after a 10 m / 100 m cave-in, and every tile request goes to 127.0.0.1:8085. `verify_forge_events.js` reads the map through `forgeMap` instead of SVG ids.

Screenshot: `img/m1-minimap.png` (day 20.4, cave-in in progress).

## Found on the way (not fixed, outside M1's files)
The MAP tab draws every node marker twice: `nodes-loaded` fires twice and `nodeMarkers.init` runs twice, leaving an orphaned second marker set (62 DOM markers for 31 nodes). The B3 test therefore compares distinct node titles.
